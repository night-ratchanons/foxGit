### Downloads

| System | File |
|---|---|
| macOS 11+ (Apple Silicon & Intel) | `FoxGit-<version>-macos.dmg` — open it and drag FoxGit to Applications |
| Windows 10/11 (64-bit) | `FoxGit-<version>-windows-x64.zip` — unzip and run `FoxGit.exe` |
| Ubuntu / Debian | `foxgit_<version>_amd64.deb` — `sudo apt install ./foxgit_*.deb` |
| Other Linux (x86-64) | `FoxGit-<version>-linux-x64.tar.gz` — unpack and run `./install.sh` |

FoxGit needs **Git** installed (macOS: `xcode-select --install`, Windows/Linux: https://git-scm.com/downloads).

**First launch:** if macOS says the app can't be opened, right-click FoxGit → **Open** (or System Settings → Privacy & Security → **Open Anyway**). On Windows, SmartScreen may show "Windows protected your PC" → **More info** → **Run anyway**.

Verify downloads with `SHA256SUMS.txt`.
